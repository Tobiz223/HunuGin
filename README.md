# Koks

Розпізнає мікрофон і звук комп'ютера в текст у реальному часі та показує готові відповіді від Gemini. Може враховувати вміст екрана й пересилати текст у Telegram.

## Запуск (Windows, Google Chrome)
1. Скопіюй `config.example.js` як `config.js` і впиши ключ Gemini API. Токен Telegram-бота необов'язковий.
2. Запусти `start.bat`.
3. Натисни «Мікрофон» або «Звук комп'ютера». Для звуку вибери весь екран і ввімкни передачу звуку.
4. У «Навчанні» додай базу знань, стиль відповідей і за потреби прив'яжи Telegram.

F6 закриває програму з будь-якого вікна (`hotkey.ps1`).

## Приватність
Звук і знімки екрана (якщо ввімкнено «Бачити екран») надсилаються в Google, а текст у Telegram, якщо його прив'язано. Попереджай співрозмовників про запис.
